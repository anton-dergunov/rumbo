How to use this page

  1. Add it to the Home Screen (iPad: Share → Add to Home Screen; Android: ⋮ → Add to Home screen / Install) and open it from there.
  2. Fill in the repos and the token, then Save and run the checks.
  3. Close the app, turn on Airplane mode, open it again: it should load, and the list of opens should say "offline".
  4. Try the Obsidian link twice: once with Obsidian closed, once with it open. Note what happened.
  5. Copy the report and paste it into docs/plans/NEXT.md. The report holds no vault text or file names.
