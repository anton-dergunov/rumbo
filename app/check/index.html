How to use this page

  1. Add it to the Home Screen (iPad: Share → Add to Home Screen; Android: ⋮ → Add to Home screen / Install) and open it from there.
  2. Fill in the repos and the token, then Save and run the checks.
  3. Close the app fully (swipe it out of the app switcher, or it only resumes and no open is recorded), turn on Airplane mode with Wi-Fi off, and open it again from the Home Screen: it should load from the service worker, and the list of opens should say "offline" or "GitHub unreachable" (Android may still say "online"). Copy the report after this step.
  4. Try the Obsidian link twice: once with Obsidian closed, once with it open. Note what happened.
  5. Copy the report and paste it into the session. The report holds no vault text or file names.
